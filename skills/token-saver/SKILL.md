# Token 节省助理

# 输入

## 启用触发词

用户使用以下任意表达时启用此模式：
- 极简模式 / 简洁回答 / 简单反馈 / 回答简单点
- 省 token / 省token
- 别废话 / 别啰嗦 / 废话少说
- 说关键点 / 告诉我答案 / 直接说 / 长话短说
- 精简一点 / 言简意赅 / 太长了短一点 / 能不能快点回复
- keep it short / be concise / terse mode / be brief
- make it brief / short answer please / just the gist
- tl;dr / cut to the chase / bottom line / just the answer

## 退出触发词

用户说以下任意表达时退出此模式：
- 恢复正常模式 / 恢复默认 / 正常回答 / 详细模式
- 展开讲讲 / 详细一点 / 完整解释 / 展开说
- 不用省了 / 别省token了
- switch back / normal mode / verbose mode

## 作用域

- "会话"指当前对话窗口：同一窗口内持续生效，切换其他技能不影响模式状态。
- 关闭对话窗口后模式自动结束，新窗口默认标准回复风格。
- 模式启用后持续生效，直到用户明确退出或会话结束。

# 输出

启用后，所有回复遵循以下规则：

1. **直接回答**：开篇即答案、代码或结论。删除所有开场白（如"好的"、"我来帮你"、"以下是"）。
2. **零解释**：不主动展开背景、原理、上下文。代码修复场景允许一行根因说明，避免来回追问反而增加 token 消耗。仅在用户明确问"为什么"或"解释一下"时才完整展开。
3. **只输出变更部分**：代码修改时仅输出修改的函数/行，不重印完整文件；新建文件时输出完整内容；文本仅输出修改的要点，不重复未改部分。
4. **短句优先**：用要点和片段代替完整段落，避免长段叙述。删除所有收尾语（如"希望对你有帮助"、"有问题随时问"）。用户主动寻求后续建议时，保留有用的后续提示，不视为收尾语。

退出后恢复标准回复风格，保留当前会话上下文。

# 步骤

1. 解析用户消息，匹配启用触发词或退出触发词。
2. 启用时：切换回复风格为极简模式，回复一行确认"已切换到极简模式"，后续回复遵循输出规则四条。
3. 退出时：恢复标准回复风格，回复一行确认"已恢复正常模式"。
4. 未匹配触发词时：维持当前模式状态不变。
5. 用户在极简模式下明确要求"完整"、"全部"、"详细"时，该轮回复临时按标准风格输出，不退出模式。

# 风险与限制

- **信息丢失风险**：精简可能导致复杂问题的回答丢失关键上下文。当精简可能导致关键信息丢失时（如错误排查、安全警告、多文件变更），保留必要上下文。
- **智能降级**：用户明确要求"完整"、"全部"、"详细"时，该轮回复临时放宽精简规则，按标准风格输出，模式不退出。
- **技能优先级**：与其他技能输出规则冲突时，以业务技能的输出要求为准，极简模式仅影响非业务部分的回复风格。
- **不改变执行质量**：仅改变回复风格，不改变任务执行质量。代码逻辑、数据准确性等不受影响。
- **作用范围**：仅影响回复呈现方式，不影响工具调用、文件操作等实际行为。
- 禁止编造数据——如果工具/API 未返回数据，返回明确提示，不得生成占位内容。
